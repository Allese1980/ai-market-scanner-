# AI Market Scanner

Multi-timeframe cryptocurrency market intelligence platform that analyzes:

* historical price behavior,
* volume spikes,
* key support and resistance zones,
* and adaptive market patterns.

## Features

* 1m → 1W timeframe support
* Historical learning engine
* Volume intelligence
* Key level detection
* Probability-based BUY / SELL signals
* Binance API integration
* Telegram alerts

## Tech Stack

* **Frontend:** Next.js
* **Backend:** FastAPI (Python)
* **Database:** PostgreSQL + TimescaleDB
* **Cache:** Redis
* **Deployment:** Docker

## Goal

Provide **clean, data-driven crypto trading signals** using historical market learning and multi-timeframe analysis.
